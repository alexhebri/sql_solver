## Design Context

### Users
People writing or learning SQL in a browser. They use SQL Solver to turn requirements into SQL or improve existing queries.

### Brand Personality
Precise, calm, practical. The interface should feel dependable and help users focus on their SQL task.

### Aesthetic Direction
Compact dark popup optimized for clarity and utility. Keep controls keyboard accessible and communicate state with clear labels and status messages.

### Design Principles
- Make the primary SQL task easy to understand and complete.
- Keep optional schema controls visible without competing with the main action.
- Explain the active schema and preserve the bundled schema when no custom schema is loaded.
- Ensure all controls work with keyboard and assistive technology.
